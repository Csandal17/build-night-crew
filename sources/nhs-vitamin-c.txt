title: Vitamin C
publisher: NHS
url: https://www.nhs.uk/conditions/vitamins-and-minerals/vitamin-c/
page last reviewed: 3 August 2020
---
You should be able to get all the vitamin C you need from your daily diet.

Taking large amounts (more than 1,000mg per day) of vitamin C can cause:
- stomach pain
- diarrhoea
- flatulence

These symptoms should disappear once you stop taking vitamin C supplements.
